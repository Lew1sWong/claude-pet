# Claude Pet 手机网页版 / PWA 📱🐾

和桌面版同款的像素宠物，做成可以装进手机主屏幕的网页应用。宠物在小舞台里走来走去，根据你的 Claude 用量切换心情（开心 / 悠哉 / 犯困 / 焦虑 / 烧钱 / 睡着）。

从 0.5.0 起，网页版和桌面版**跑的是同一套代码**：用量解析、心情、菜园和乌鸦、趋势折线与额度天气、每周成绩单、中英文文案、像素素材、8-bit 音效、面板渲染，全部由 `desktop/scripts/sync-web.js` 从桌面端生成到 [`shared/`](shared/)（`cd desktop && npm run sync-web`；测试 `webShared.test.js` 会在生成文件过期时报错）。`app.js` 只剩页面粘合层。

## 本地预览

是纯静态文件，但 PWA（service worker）需要通过 http 访问，不能直接用 `file://` 打开。任选一种起个本地服务：

```bash
cd web
npx serve .            # 或
python3 -m http.server 8080
```

然后手机和电脑连同一个 Wi-Fi，手机浏览器打开 `http://<电脑IP>:8080`。

## 装到手机主屏幕

- **iPhone（Safari）**：打开网页 → 点底部「分享」→「添加到主屏幕」。
- **Android（Chrome）**：会弹「添加到主屏幕」，或菜单里手动选。

之后就有一个独立图标（小克 ✦），全屏打开像 App。

## 有什么

- **用量面板**：5h / 周 / Fable ✦ 等模型专属额度 / 额外用量 💸 进度条、重置倒计时、本周去向。
- **📈 趋势与额度天气**：自动获取模式下每次刷新记一笔（本地保存 7 天），画两条 8-bit 折线，预测照当前速度能不能撑到重置（☀️ 🌤 🌧 ⛈），天气差时面板里真的下像素雨、打闪电；预计重置前用光会弹一次预警。
- **🌱 像素菜园 + 🐦‍⬛ 乌鸦**：三块地，点空地播种，长势跟心情走；成熟会发光，点一下收获喂宠物；放着不收，乌鸦会来叼走（点它赶跑）。乌鸦只在页面开着时计时。
- **📋 每周成绩单**：右上角 📋，评级 S/A/B/C + 称号（夜猫子、烧 token 狂魔……）、最猛的一天、深夜占比、菜园战绩、小建议；每周重置自动给上一周打分。
- **🔊 8-bit 音效**、**中 / 英文**（跟随系统或手动选）、**系统通知**（可选，开启后页面在后台时乌鸦来了、额度预警等会推送）——都在 ⚙ 里。
- 演示模式也带一份两天的示例历史，所以不填任何东西也能看到折线、天气和成绩单长什么样。

## 用量数据从哪来（点右上角 ⚙）

手机上没有本机的 Claude Code 凭证，而且手机浏览器**直连 Anthropic 接口通常会被 CORS 拦截**，所以有三档方案，按推荐顺序：

1. **手动 %（最稳，推荐）**：在桌面用 `claude` 的 `/usage` 看一眼当前 5h / 周百分比，填进「手动 5H % / 周 %」（有 Fable ✦ 额度的话也可以填）。宠物立刻按这个心情演出。适合「就想要个陪伴 + 提醒别超额」。手动模式没有历史曲线。
2. **中转地址（自动获取）**：如果你有一台服务器 / Cloudflare Worker 能转发请求并补上 CORS 头，把它的地址填进「代理 / 中转地址」，再填 Token，就能自动拉实时数据，趋势、天气、预警、成绩单也都会活过来。中转端要做的事：收到请求 → 带上 `Authorization` 和 `anthropic-beta: oauth-2025-04-20` 转发到 `https://api.anthropic.com/api/oauth/usage` → 在响应里加 `Access-Control-Allow-Origin: *`。
3. **直接填 Token 试试**：少数环境（或装成 PWA 后）可能能直连，可以点「测试自动获取」看看。被 CORS 拦就回到上面两种。

> Token、设置、历史、菜园都只存在你手机浏览器的 localStorage，不会上传到任何服务器。
> 不填任何东西时是**演示模式**，宠物用一组示例数据自娱自乐。

## 和桌面版的关系

[`shared/`](shared/) 里的每个文件都是生成的（文件头有标注），改了桌面端的 `lib/` 或 `renderer/` 之后在 `desktop/` 里跑一次 `npm run sync-web` 即可同步；像素素材同样由 `desktop/tools/sprites.py` 生成到两边。所以网页版的宠物、菜园、文案永远和桌面版一致：小橘 🐱 / 柴柴 🐶 / 布朗 🐻 / 团子 🐰 / 小狐 🦊 / QQ 🐧 / 小克 ✦。

## 部署到公网（可选）

整个 `web/` 目录可以直接丢到任意静态托管：GitHub Pages、Cloudflare Pages、Vercel、Netlify 都行，零构建。配合上面的「中转地址」就能在任何手机上看实时用量。
